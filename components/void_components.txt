# name|packages|files (repo paths)|services|group|default
# group = the tab in shh config: empty = features, misc = programs we always use;
# settings = its own line in settings (maxhz); xwayland = settings > xwayland; editor = settings > editor; files = settings > file manager. Anything else: sudo xbps-install NAME yourself.
# default: empty = on, no = off
